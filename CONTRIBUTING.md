# Contributing

Thank you for considering a contribution.

## Development

Install dependencies with Composer, then run the checks before opening a pull request:

```bash
composer test
composer analyse
```

Keep changes focused, add or update tests for behavioral changes, and follow the existing PSR-12 style. Public APIs and documentation must reflect implemented behavior only.

## Pull requests

Describe the problem and solution, include relevant tests, and link related issues. Do not include secrets, account IDs, or credentials in code, fixtures, or descriptions.

By contributing, you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
